# waycrest-marketing-assets

Public images and media used in Waycrest marketing: emails, announcements, landing pages and social posts.

This repo is public on purpose. Email clients and other sites load these files straight from GitHub, so keep anything private or unreleased out of it.

## Layout

| Folder   | What's in it                                                                 |
| -------- | ---------------------------------------------------------------------------- |
| `intro/` | Intro email images: `ai.jpg` (Tackle AI), `mail.jpg` (Tackle Mail), `pick.gif` (Tackle Pick) |

Add a new folder for each campaign or use.

## Linking to a file

Use the raw URL:

```
https://raw.githubusercontent.com/Waycrest/waycrest-marketing-assets/main/<folder>/<file>
```

For example, `https://raw.githubusercontent.com/Waycrest/waycrest-marketing-assets/main/intro/mail.jpg`.

Don't rename or delete a file after it has gone out in an email. Messages already sent will still point at the old path.
